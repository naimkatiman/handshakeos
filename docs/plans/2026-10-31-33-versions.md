# 33 versions of HandshakeOS

Goal: ship 33 versions, each one bold change aimed at conversion or look and feel, each committed, tagged `vN`, and live on Cloudflare Workers.

- Live: https://handshakeos.m-naim.workers.dev
- Branch: `ship/versions` (worktree `D:\Handshakeos-ship`). Every version is a commit plus tag `vN`.
- Log: [docs/versions.md](../versions.md), one entry per version.

## Rules for each version

1. Look at the live site first, pick the single biggest weakness.
2. One bold change, not a tweak.
3. typecheck + `next build` green, verified in a browser at 1366x768 and 390x844, reduced motion checked when motion changes.
4. Commit, tag, then `npm run cf:deploy` from a clean tree. Smoke-test the live URL.

## Assets

- Grok CLI (`grok -p "/imagine ..."`) headless, saved to `assets/generated/vNN-*` with unique names, never overwritten. Shipped copies go to `public/landing/`.
- Budget: at most 1 to 2 images per version. Video (`/imagine-video`) only where a version needs it.

## Scroll-craft brief (self-authored under explicit creative delegation)

- Grammar: live surface. The product's own audit is the spectacle, not a stock video.
- Signature move: the evidence audit. Four real messages from one deal are scanned, stamped, and the funnel only advances on completed evidence. The hearsay message makes the funnel lunge red and fall back.
- Peak: the hearsay refusal. "It's the site where a rumour tries to close a deal and gets caught."
- Feeling curve: recognition (calm, the table after a mixer) > unease (the pipeline counts promises) > suspense then vindication (the audit) > clarity (three words, on paper) > resolve (bring last night's conversation).
